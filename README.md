RO_BuffIcons_resources
=========================

Overview
--------
This repository contains custom Rose Online buff icons resource packs for RO_BuffIcons_resources. Each top-level folder is a separate profile/theme with its own buff icons.

Current profiles
----------------
- Regal


Repository layout
-----------------
Root/
- .default/      (default/recovery pack with Rednim cursors)
- Regal/         (Regal-themed UI pack)
- README.md      (project documentation)
- manifest.json  (repository metadata)

-----------------
